\textbf{Centralized Training-Based Multi-Agent Reinforcement Learning for LEO Satellite Handover}\\
Propose a handover strategy for LEO satellite networks using multi-agent reinforcement learning to optimize network performance and reduce handover frequency.
\begin{itemize}[leftmargin=16pt, topsep=2pt, itemsep=0pt]
    \item Using Centralized Training with Decentralized Execution (CTDE) framework to train agents representing ground terminals for handover decisions
    \item Designed reward function considering factors like signal strength, load balancing, and handover costs
    \item Evaluated performance through simulations, demonstrating improved network throughput and reduced handover frequency compared to traditional methods
\end{itemize}
